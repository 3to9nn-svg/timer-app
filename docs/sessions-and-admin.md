# セッション・管理者モード

## 公開への反映

この更新は `timer-server` と `timer-app` の両方に反映してください。先にサーバー、次にフロントエンドを更新します。`APP_PASSWORD` と `DATABASE_URL` は既存の設定を引き続き使います。追加の環境変数や手動のデータベース操作は不要です。

既存イベントはフリーランセッションとして読み込みます。ランオーダー・セッション種別・スタート済み状態は、イベントの記録と同じデータベースに保存されます。サーバー更新前の画面では、新機能に更新が必要であることを表示します。

## エントリーとスタート

- エントリー管理の「表示順」で、追加順・カーナンバー順・名前順を切り替えます。この並べ替えは表示のみで、登録順やランオーダーを書き換えません。
- フリーランセッションは、毎回車両を選んでスタートします。選択肢はカーナンバーの数値順（例：2、30、100）です。
- スタート画面の「セッション」でラリーセッションへ切り替えます。走行中の車両がいる間は切り替えられません。
- ラリーでは、車両を1台ずつ、または全エントリーを番号順にランオーダーへ追加します。同じ車両を複数回追加することもできます。1回の追加は500台、イベント全体のランオーダーは5000件までです。
- 「START」で待機列の先頭車両をスタートし、次の車両へ進みます。先頭車両が既に走行中の場合は、フィニッシュを待つか、スキップ・並べ替えをしてください。
- 上下ボタンで待機車両の順番を変更できます。「スキップ」はその出走枠を待機列から外し、スキップ済み欄の「末尾に戻す」で復帰します。
- スタート済みの枠は再利用しません。計測取消後などに再出走させる場合は、車両をランオーダーへ再追加してください。
- 別端末が先に出走順を更新した場合、古い画面からの操作は受け付けず、最新の順番を確認するよう表示します。

## 管理者モード

トップまたは右上メニューから「管理者モード」を開き、ログイン用の `APP_PASSWORD` をもう一度入力します。通常ログインと同じ共有パスワードなので、別の管理者専用パスワードによる権限分離ではありません。

再認証は接続ごとに15分間有効です。管理者画面から離れる、通信が切れる、ページを再読み込みする、または有効期限が切れると再認証が必要です。サーバーも、一覧取得・CSV保存・削除の各操作で管理者認証を確認します。

- CSV保存：確認後、そのイベントの全エントリーと全リザルトをCSVに保存します。「種別」で登録情報と計測結果を区別できます。走行中の未確定タイムは含みません。
- 削除：確認後、そのイベントのエントリー・出走順・リザルトをサーバーから削除します。元には戻せません。
- 全削除：確認したイベント一覧をまとめて削除します。確認中にイベントが追加・削除された場合は処理を中止します。
- 開催中でも、走行中の車両がいなければ削除できます。現在のイベントを削除した場合は「イベント未開始」に戻ります。
- 走行中の車両があるイベントは削除できません。全削除も、いずれかのイベントに走行中の車両があれば実行できません。

CSV保存・個別削除・全削除の確認でキャンセルした場合は、それぞれの処理は実行されません。
