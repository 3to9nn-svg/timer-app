# イベントを消えないようにする公開設定

今回の更新では、イベント・エントリー・走行中の開始時刻・リザルトを外部の PostgreSQL に保存します。
Render のサーバーが停止・再起動しても、同じデータベースに接続すれば記録を復元します。
イベントは「開始」「終了」ボタンで管理し、終了後も記録を保持します。

## 最初の更新前

旧バージョンの記録はサーバーのメモリ内だけにあり、新しいデータベースへ自動移行されません。
開催中のイベントを避けて更新し、残したい旧リザルトは先にCSV保存してください。
消えてしまった旧データを今回の変更で復元することはできません。

## 1. PostgreSQL を用意する

無料枠のある外部サービスとして [Neon](https://neon.com/) を利用できます。
既存の PostgreSQL がある場合は、それを使用しても構いません。

1. Neon にサインアップまたはログインします。
2. Free プランでプロジェクトを作成します（例：`rally-timing`）。Render のサーバーに近いリージョンを選びます。
3. プロジェクトの **Connect** から接続文字列をコピーします。
4. `postgresql://` で始まる URL 本体を使います。`psql` コマンドや外側の引用符は含めません。
5. 接続文字列に付いている SSL などのオプションは残します。

接続文字列にはデータベースのパスワードが含まれます。GitHubやチャットに貼らず、次のRender設定に直接入力してください。
無料枠には容量・利用量の上限があります。契約時の条件は [Neonの料金ページ](https://neon.com/pricing) で確認してください。

## 2. Render に設定する

1. Render の **timer-server** サービスを開きます。
2. **Environment → Add Environment Variable** を開きます。
3. Key に `DATABASE_URL`、Value にコピーした接続文字列を入力します。
4. **Save only** で保存します。既存の `APP_PASSWORD` はそのまま残します。
5. `timer-server` の修正コードをGitHubへ反映し、最新コミットをデプロイします。
6. `timer-app` の修正コードもGitHubへ反映し、デプロイします。

`DATABASE_URL` はサーバーだけに設定します。フロント側の `VITE_` 変数には入れません。
サーバー起動時に保存テーブルを自動作成します。SQLを手動実行する必要はありません。
接続先のユーザーには、そのデータベース内でテーブルを作成・読み書きする権限が必要です。
`DATABASE_URL` が未設定、またはデータベースに接続できない場合は、データが消えるメモリ保存へ切り替えずに起動を停止します。

## 3. イベントを使う

1. アプリにログインし、**イベント管理** または **エントリー管理** を開きます。
2. イベント名を入力し、**イベントを開始** を押します。
3. 車両を登録し、これまでどおりスタート・フィニッシュを計測します。
4. 走行中の車両がなくなったら **イベントを終了** を押します。
5. 終了済みイベントは変更できませんが、リザルトの閲覧・CSV保存は可能です。
6. 次のイベントを開始しても、過去のイベントは残ります。

リザルト画面の **イベント** で過去の記録を選べます。
**カーナンバー** で車両を絞り込み、**タイム順／新着順** を切り替えられます。
タイム差は絞り込んだ範囲のベストタイムとの差です。CSVにも選択したイベント・車両・並び順が反映されます。

## データ保持と運用

- 時間経過やイベント終了による自動削除は行いません。全件削除の代わりに新しいイベントを開始します。
- 再デプロイ・再起動後は再ログインが必要ですが、同じデータベースに保存した記録は復元されます。
- Render無料サービスのスリープ・起動待ち自体をなくす変更ではありません。再接続後に保存済みデータを表示します。
- データベース障害時は保存成功を表示しません。エラーが出たら最新状態を確認して再試行してください。
- データベース自体を削除・初期化したり、`DATABASE_URL` を別の空のデータベースへ変更すると以前の記録は表示できません。
- Socket.IO配信と認証セッションは1台のサーバーで運用する構成です。複数インスタンスへ増やす場合は共有配信・認証ストアが別途必要です。
- 本番での保持期間・容量はデータベースサービスの契約に依存します。イベント後のCSV保存も利用できます。
